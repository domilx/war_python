# War

## `war.py` (Pygame Version)
This is the Pygame version of the War game.

### Setup Instructions:
1. Install Pygame:
   ```bash
   $ pip3 install pygame
   ```

2. Run the game:
   ```bash
   $ python3 war.py
   ```

### MacOS Instructions:
1. Create and activate a virtual environment:
   ```bash
   $ python3 -m venv path/to/venv
   $ source path/to/venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   $ python3 -m pip install pygame
   ```

3. Run the game:
   ```bash
   $ python3 war.py
   ```

## `game.py` (Text-Based Version)
This is the text-based version of the War game.

### Run the game:
